# Bedtime Story Generator for Kids

A mini GenAI project that generates age-appropriate moral stories
using Google Gemini API, with optional read-aloud audio via gTTS.

## Inputs
Age, characters, moral, language (English/Hindi)

## Tech Stack
Python, Gradio, Google Gemini API, gTTS

## How to run
1. Open the notebook in Google Colab
2. Add your Gemini API key (https://aistudio.google.com/apikey)
3. Run all cells and open the Gradio link
